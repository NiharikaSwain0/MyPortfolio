# Futuristic Portfolio - Niharika Swain

A modern, responsive, and futuristic portfolio website built with a glass-morphism design. This portfolio showcases projects, education, technical skills, and certifications with a focus on a high-end UI/UX.

## 🚀 Features

- **Futuristic UI**: Glass-morphism design with neon accents and glowing effects.
- **Dynamic Background**: Interactive particle background and mouse-follow glow effect.
- **Responsive Design**: Optimized for all screen sizes, from large monitors to mobile devices.
- **Theme Toggle**: Switch between Dark and Light modes with persistent storage.
- **Typing Animation**: Dynamic role display in the hero section.
- **Google Sheets Integration**: Contact form submissions are automatically saved to a Google Sheet.
- **Scroll Reveal**: Sections animate into view as you scroll.

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Grid/Flexbox, and complex animations.
- **JavaScript (Vanilla)**: Interaction logic and background effects.
- **FontAwesome**: High-quality icons.
- **Google Fonts**: Inter font family for a clean look.

## 📂 Project Structure

- `index.html`: Main structure and content.
- `style.css`: Styling, layouts, and animations.
- `script.js`: Interactive logic, particles, and form handling.
- `assets/`: Images and other static files.

## 📧 Contact Form Setup

The contact form is configured to work with Google Sheets via Google Apps Script. 
To set it up:
1. Create a Google Sheet with headers: `name`, `email`, `message`, and `timestamp`.
2. Create a Google Apps Script as a Web App.
3. Update the `scriptURL` in `script.js` with your deployment URL.
